###### This is a repository for custom skills.
---
This is where I would like to create and maintain all of my custom skills and workflows
### Rules
---
- All skills should be self contained, with optional skill resources living in the parent skill folder. 
- Skills are the primitive building blocks: pure machinery, each invocable alone and in any order, naming no tracker target or document home. Workflows own routing, homes, and sequencing.
- No pipeline is mandatory. A sequence is written into a workflow only after it recurs in practice, and a hook that fires a skill on an event only after the manual form has proven itself.
- All skills should be developed ourselves to avoid license conflicts.
